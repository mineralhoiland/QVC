# QVC v0.4.1

Public compilation of the QVC / TEVC preprint, with Zenodo metadata.

- Manuscript dated 8 September 2026 (TeX, figures, bibliography, supplements)
- Frozen fat-torus parameters matching `paper/macros.tex`
- Python verification, dictionary, and vortex-sector codes
- Crystal structures and visualization suites (visualizations are not the numerical lock)
- `.zenodo.json` so GitHub releases can mint a DOI (CC BY 4.0 for the compilation; MIT for `compute/` and `sim/`)

v0.4.0 on GitHub did not produce a Zenodo record: the webhook conflicted on duplicate release events, and the tagged tree had no `.zenodo.json` (CITATION.cff used a dual SPDX license Zenodo often rejects). Do not reuse the `v0.4.0` or `release` tags for minting.
